# Data Engineering Internship Projects

Практические проекты по инженерии данных, демонстрирующие различные технологии и подходы к работе с данными.

## 📂 Проекты

### 🐘 [PostgreSQL Audit](./postgress_audit/)
**Транзакционная система аудита пользователей (OLTP)**

Система для отслеживания и аудита операций пользователей с использованием PostgreSQL. Включает триггеры, логирование изменений и отчетность по активности.

**Технологии**: PostgreSQL, триггеры, функции аудита

### 🚀 [ClickHouse Events Analytics](./clickhouse_events/)
**Аналитическая система событий с расчетом Retention (OLAP)**

OLAP-решение для анализа пользовательских событий с автоматической агрегацией данных через Materialized Views. Расчет метрик Retention и поведенческой аналитики.

**Технологии**: ClickHouse, Materialized Views, State/Merge функции, AggregatingMergeTree


### 🍃 [MongoDB User Archivation](./mongobd_archive_users/)
**Система архивации неактивных пользователей**

Ежедневная система для автоматического перемещения неактивных пользователей в архивную коллекцию. Поиск пользователей по критериям: регистрация >30 дней назад и отсутствие активности >14 дней.

**Технологии**: MongoDB, PyMongo, агрегационные пайплайны, JSON отчеты

## 🔄 Kafka Data Pipeline
**Надежный пайплайн передачи данных между системами**

Устойчивое решение для миграции данных из PostgreSQL в ClickHouse через Apache Kafka с защитой от дублирования. Producer читает данные из PostgreSQL и отправляет в Kafka, а consumers сохраняют данные в целевые системы.

**Особенности**:
- Защита от дублирования через флаг `sent_to_kafka`
- Параллельная запись в PostgreSQL и ClickHouse
- Автоматическое создание тестовых данных

**Технологии**: Apache Kafka, PostgreSQL, ClickHouse, Python

**Файлы**:
- `ch_producer.py` - Producer с логикой защиты от дублирования
- `clickhouse_consumer.py` - Consumer для ClickHouse
- `postgress_consumer.py` - Consumer для PostgreSQL
- `docker-compose.yml` - Конфигурация Kafka и Zookeeper

### 🎛️ Airflow DAG Generator
**Автоматический генератор DAG'ов для Apache Airflow**

Система автоматической генерации DAG'ов из Python и SQL скриптов. Программа анализирует исходные файлы, извлекает метаданные и создает единый мастер-DAG со всеми задачами. Конкурсная работа стажировки.

**Особенности**:
- Автоматический парсинг Python функций и SQL команд
- Извлечение метаданных из специальных комментариев
- Генерация единого DAG с автоматическими зависимостями
- Поддержка Docker для быстрого развертывания
- Соответствие всем требованиям ТЗ конкурсного задания

**Технологии**: Apache Airflow, Python, Jinja2, Docker, PostgreSQL

**Ключевые файлы**:
- `generator.py` - основной генератор с логикой парсинга
- `templates/master_template.j2` - Jinja2 шаблон для генерации DAG
- `scripts/` - примеры Python и SQL скриптов с метаданными
- `dags/master_generated_dag.py` - сгенерированный DAG файл
- `docker-compose.yml` - конфигурация Airflow в Docker
